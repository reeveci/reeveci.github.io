What is Reeve? ​

Reeve is an extensible open source CI / CD solution written in Go. It can be integrated into various existing systems via its plugin system.

Reeve runs pipelines based on user defined triggers. Each pipeline step is executed in dedicated containers, resulting in a high degree of reproducibility, isolation, and customizability.
